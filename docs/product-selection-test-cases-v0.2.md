# 海外电子产品选购应用 测试用例 v0.2

本清单用于验收 [PRD v0.2](./product-selection-prd-v0.2.md) 定义的 Next.js 纯前端购物应用。每条用例包含需求映射、前置条件、操作和可判定结果；所有用例均为首版验收范围。当前状态全部为“未执行”，不代表应用已经通过测试。

日期：2026年10月10日。规则冲突以 PRD v0.2 为准，测试发现歧义时先补齐规则再实施，不能用实现现状反向替代需求。

覆盖统计：71项有编号需求，165条验收用例；含27条列表、17条详情、27条购物车、15条结账表单、26条支付订单、24条数据状态、14条响应式与可访问性、11条工程交付、4条端到端及体验验证用例。参数化用例中的每组输入均须执行。

## 1 执行约定和测试数据

### 1.1 通用前置条件

除用例另有说明外：使用生产构建的静态站点、英文/USD、可用 IndexedDB、BASE 数据、全新演示会话、空购物车、无本地扣减、默认 Standard、支付结果 Success。用例独立执行，每条结束重置本应用数据。无需真实邮箱、地址、银行卡或支付账号。

金额全部按美分断言；页面金额同时检查 USD/en-US 显示。凡购物车写操作，检查行数、SKU、数量、角标和金额；凡失败写操作，比较操作前后已提交业务状态，允许错误消息/失败attempt记录变化，不允许订单、购物车数量或库存意外变化。凡模拟成功，检查订单1条、对应库存准确扣减、购物车清空、费用快照正确。

时间用可控时钟，不通过长时间人工等待测试30天过期；成功/拒付/技术失败推进2秒，超时推进8秒，Undo推进5秒。跨标签使用相同origin与同一浏览器profile；跨设备/隔离profile用例使用独立存储。模拟故障通过明确的测试fixture或浏览器权限设置触发。
